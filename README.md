# Склад воды — Android-приложение

Приложение работает полностью без интернета. Внутри — та же страница, что и в браузере
(`app/src/main/assets/index.html`), открытая во встроенном окне Android.

## Вариант 1. Сборка в Android Studio (на компьютере)

1. Установите Android Studio: https://developer.android.com/studio (бесплатно, Windows / Mac / Linux).
2. Распакуйте архив `SkladVody.zip` в любую папку.
3. Android Studio → **File → Open** → выберите папку `SkladVody`.
4. Подождите, пока внизу закончится «Gradle sync» (первый раз 5–15 минут, нужен интернет).
   Если Studio предложит установить недостающий SDK — соглашайтесь.
5. Меню **Build → Build App Bundle(s) / APK(s) → Build APK(s)**.
6. Справа внизу появится «APK(s) generated» → нажмите **locate**.
   Файл: `app/build/outputs/apk/debug/app-debug.apk`.
7. Перекиньте APK на телефон (кабель, Telegram, WhatsApp «себе») и откройте его.
   Телефон спросит разрешение «Установка из неизвестных источников» — разрешите.

Можно ставить сразу на подключённый по кабелю телефон: включите на телефоне
«Отладку по USB» (Настройки → О телефоне → 7 раз нажать «Номер сборки» → Для разработчиков)
и нажмите зелёный ▶ **Run** в Android Studio.

## Вариант 2. Сборка на GitHub (без установки программ)

1. Зарегистрируйтесь на https://github.com.
2. Создайте новый репозиторий (**New repository**, можно Private).
3. **Add file → Upload files** → перетащите всё содержимое папки `SkladVody`
   (вместе с папками `.github`, `app`, `gradle`). Нажмите **Commit changes**.
   Если папка `.github` не загрузилась (она скрытая), создайте файл вручную:
   **Add file → Create new file**, имя `.github/workflows/build-apk.yml`,
   и вставьте содержимое этого файла из архива.
4. Откройте вкладку **Actions** — сборка запустится сама (около 5 минут).
5. Когда появится зелёная галочка, откройте сборку → внизу **Artifacts → SkladVody-apk** — скачайте.
6. В скачанном zip лежит `app-release.apk` — установите его на телефон.

## Как обновить приложение после изменений

1. Замените файл `app/src/main/assets/index.html` новой версией.
2. В `app/build.gradle.kts` увеличьте `versionCode` на 1 (например, 1 → 2).
3. Соберите APK заново и установите **поверх** старого — все записи сохранятся.
   Не удаляйте старое приложение перед установкой: удаление стирает данные.

## Перенос данных из браузерной версии

В старой версии: Настройки → «Скопировать копию» → отправьте текст себе.
В приложении: Настройки → «Восстановить» → вставьте текст.
